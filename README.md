# 🔐 ACE TEXT - Text Encoder & Decoder

ACE TEXT ek simple aur fast web application hai jo FastAPI aur Caesar Cipher algorithm ka use karke text ko encode aur decode karta hai.

---

## ✨ Features

- **Text Encoding:** Apne secret text ko Shift Key se encode karein.
- **Text Decoding:** Encoded text ko wapas original text mein convert karein.
- **Clean & Responsive UI:** Mobile aur Desktop dono par smoothly chalne wala modern design.
- **Fast Performance:** FastAPI backend speed aur reliability ke liye.

---

## 🛠️ Tech Stack

- **Backend:** Python, FastAPI, Uvicorn, Jinja2
- **Frontend:** HTML5, Modern CSS3
